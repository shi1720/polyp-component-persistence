# Polyp component-persistence audit

Research by Shivam Gupta, Independent Researcher, India.

This artifact audits largest-connected-component filtering in recall-calibrated polyp segmentation. It includes the final manuscript source, original analysis code, complete per-image threshold-path statistics, paired random-split results, and upload-sized conference graphics. No benchmark images, third-party model source, or model weights are redistributed.

## Reproduce analysis from released sufficient statistics

Use Python 3.12 with NumPy, SciPy, and pandas. From the repository root:

```bash
python src/evaluate.py --paths results/paths_g257_c2_t10.npz --manifest results/manifest.json --out work/reanalysis
python -m unittest discover -s src -p 'test_*.py' -v
```

The results are deterministic given the recorded paths and NumPy version. Split spread measures partition sensitivity, not independent-study uncertainty.

## Reproduce inference and threshold paths

Install the recorded environment in a dedicated virtual environment:

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-lock.txt
.venv/bin/python src/fetch_assets.py
.venv/bin/python src/infer.py --data work/polyps_data --upstream work/upstream --weights work/PraNet-19.pth --out work/cache
.venv/bin/python src/paths.py --cache work/cache --out work/recomputed --grid 257 --connectivity 2
.venv/bin/python src/evaluate.py --paths work/recomputed/paths_g257_c2_t10.npz --manifest work/cache/manifest.json --out work/recomputed
```

The download script pins the upstream architecture revision and verifies data/checkpoint SHA-256 checksums. Verify upstream access and research-use conditions before running. MPS is used if available, otherwise CPU. Numerical differences across hardware can change pixels close to a threshold; CPU/MPS checks from the reported run are recorded in `results/inference.json`. There is no model training or model selection.

For sensitivity paths repeat `src/paths.py` with `--grid 513` and with `--connectivity 1`. Recreate figures with:

```bash
.venv/bin/python src/figures.py --root . --cache work/cache --data work/polyps_data
```

## Build manuscript

From `paper/`, run `tectonic manuscript.tex`. The included results text and tables correspond to the recorded experimental run. Figures are generated by `src/figures.py`. The full manuscript is supporting documentation; IMKASID accepts a structured abstract and at most three graphical attachments.

## Statistical and clinical scope

The endpoint is mean per-image fraction of annotated polyp area omitted. It is not lesion detection sensitivity, adenoma detection rate, complete resection, or a per-patient guarantee. Exact RGB duplicate removal does not establish patient or sequence independence. The fixed released test images are split for calibration sensitivity, not a new prospective clinical cohort. Source-held-out results are distribution-shift stress tests.

## Attribution and novelty

Conformal risk control is from Angelopoulos et al. (ICLR 2024). In particular, the suffix-loss envelope is already Corollary 1 of that paper. The component-persistence construction is a running union and has an elementary minimal-nested-superset property; it is not a new general calibration theorem. Connected morphology is established. The contribution is the reproducible final-mask audit and the measured recall/area trade-offs. See `LITERATURE_REVIEW.txt` for close prior work and `PROTOCOL.txt` for the exploratory analysis plan recorded before prediction analysis.

For the transformer replication:

```bash
.venv/bin/python src/infer.py --model pvt --data work/polyps_data --upstream work/upstream_pvt --weights work/PolypPVT.pth --out work/cache_pvt
.venv/bin/python src/paths.py --cache work/cache_pvt --out work/recomputed_pvt

```

The Polyp-PVT loader omits only the redundant initialization checkpoint load before the full checkpoint is strictly loaded. Its adaptive-average-pooling operation runs on CPU when MPS is selected; this preserves the mathematical operation and is checked against complete CPU inference for the first three images.
